📚 Documentation

smol.js - Minimal Web Component framework with SSR support.

  • ✅ Only 3.05 KB gzipped
  • ✅ Zero dependencies
  • ✅ TypeScript-first
  • ✅ SSR ready

Use smolComponent() to create components:

import { smolComponent, html, css } from 'smol.js';

const MyBtn = smolComponent({
  tag: 'my-btn',
  styles: css`button { padding: 1rem 2rem; }`,
  template() {
    return html`<button><slot></slot></button>`;
  }
});

Signals

const count = smolSignal(0);
count.value++;
count.subscribe(() => console.log(count.value));

State

const user = smolState({ name: 'Alice' });
user.name = 'Bob';

Events

html`<button @click=\${handler}>Click</button>`

Attributes

html`<button ?disabled=\${isDisabled}>Submit</button>`
 
smolComponent({
  connected() { console.log('mounted'); },
  disconnected() { console.log('unmounted'); },
  attributeChanged(name, old, new) { }
});
 
import { renderComponentToString } from 'smol.js';
const html = renderComponentToString(MyBtn);
 
# Create component
smol new component my-btn

# Dev server
smol dev

# Build
smol build --ssr
